# 证据判据：什么才算「查到了」

旧的 0.62 分体系有个致命问题：**「某站有这个名字」和「本人主页写着学校」拿到差不多的分**。读完你不知道该信哪条。

改用**五档 + 门槛**：档位由「证据类型」决定，不由「找到了几条」决定。

## 一、五档

| 档 | 含义 | 必须满足 | 能不能写进结论 |
| --- | --- | --- | --- |
| **已核实** | 可以当事实用 | 直接自述 / 官方记录 / 唯一标识互证，且排除同名 | ✅ 可以 |
| **高度可能** | 可以当工作假设 | ≥2 条独立证据指向同一结论，但没有直接自述 | ✅ 可以，须注明「高度可能」 |
| **推测** | 只是方向 | 单一线索，或弱证据组合 | ⚠️ 只能写成「推测」并给出验证方法 |
| **线索** | 某处出现过 | 仅说明存在/被提及，尚未指向具体人 | ❌ 不进结论，进「待查」 |
| **已排除** | 有反证 | 找到同名不同人的证据、时间矛盾、地点矛盾 | ✅ 单列「排除项」 |

**铁律：只有「线索」档的材料，不许升格成结论。** 「B站有这个昵称」永远是线索，不是「已核实」。

## 二、证据类型 → 强度

| 强度 | 证据类型 | 举例 |
| --- | --- | --- |
| **S** | 官方/实名记录 | 工商登记、裁判文书、政府采购中标公告、学校公示名单、专利发明人、学历认证 |
| **A** | 本人自述 | 主页签名写学校/单位/邮箱、公众号作者简介、论文作者单位、GitHub profile |
| **B** | 唯一标识互证 | 同一手机号/邮箱/头像/外链出现在两个平台；同一自拍照 |
| **C** | 属性组合吻合 | 昵称 + 城市 + 兴趣/职业三项一致，但无唯一标识 |
| **D** | 仅名称相同 | 同名、同昵称、同头像（普通图片） |
| **E** | 反证 | 时间冲突、地点冲突、自称年龄与学历矛盾 |

判定规则：

- **S / A** → 直接支撑「已核实」（仍需排除同名，见第三节）
- **B** → 支撑「已核实」或「高度可能」，取决于标识的唯一性（手机号 > 邮箱 > 头像）
- **C** → 最高到「高度可能」，必须 ≥2 条独立
- **D** → 只能「线索」
- **E** → 进「排除项」，并回头检查是不是把两个人的线索拼在了一起

## 三、同名消歧：必须做的四步

中文同名是最大的误判来源。任何「已核实」之前，走完这四步：

1. **三件套对齐**：姓名 + 单位/学校 + 城市，至少两项一致。
2. **时间线自洽**：入学年份 ↔ 年龄 ↔ 工作年限 ↔ 发言时间，不能矛盾。
3. **唯一标识**：找一个只有这个人会有的东西（手机号、邮箱、自拍照、独特作品）。
4. **主动找反证**：专门搜「同名 + 另一个城市/单位」，看能不能把人分开。找到了就写进「排除项」。

四步里只做到 1–2 步 → 最高「推测」。

## 四、常见误判（都见过）

| 现象 | 为什么错 | 怎么纠正 |
| --- | --- | --- |
| 同一段文字出现在 10 个号 | 都是搬运，只有一个最早 | 追最早发布时间，其余当噪声 |
| 头像一样 | 网图/表情包/明星照被大量复用 | 用图片反查看是否到处都有 |
| 昵称一样 | 中文昵称重复率极高 | 昵称只能当线索 |
| 「听说他是……」 | 论坛传言 | 只能进「线索」 |
| 百科/新闻里有 | 对公众人物有效，对普通人几乎为零 | 别把「有百科」当「查到了」 |
| AI 生成的人物介绍 | 现在很多「人物资料」是模型编的 | 必须回到一手页面；无出处的介绍一律不用 |
| 截图 | 可伪造 | 必须找到可访问的原始页面 |
| 关注/粉丝列表 | 只能说明社交关系，不说明身份 | 关系 ≠ 身份 |

## 五、写报告的表述规范

- 已核实：`B站账号「罗翔说刑法」（mid 517327498）为本人`，附主页链接 + 签名原文。
- 高度可能：`该账号极可能属于目标（三条独立证据一致：同校、同城、同一作品）`。
- 推测：`疑似同一人，依据是昵称与城市一致；验证方法：私信确认/看历史发言时间线`。
- 线索：`搜到同名账号 3 个，均未确认`。
- 已排除：`「张伟·杭州」与目标是两个人（不同学校，时间冲突）`。

**不要写概率数字。** 0.62 这种精度是假的，读者只会误以为你很确定。写档位 + 依据，比写分数诚实得多。

## 六、一条自检

报告写完，逐条问：

> 如果有人拿这条结论来质疑我，我能立刻给出一个可点开的链接和一段原文吗？

给不出 → 降到「线索」，或删掉。
