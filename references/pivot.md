# 线索扩展手册：拿到 A 之后该查什么

查人是一串「换乘」。单个线索几乎都不够，但**线索之间能互相喂**。
每次拿到新事实，都过一遍这张表，问：这条还能拿去换什么？

## 一、主表

| 已知 | 能推出什么 | 下一步怎么查 | 依据 |
| --- | --- | --- | --- |
| **昵称 / 英文 ID** | 同名平台账号、大小号 | `bili-user` 搜昵称 → mid；`variants` 生成变体再搜；搜「昵称 + 平台名」 | 很多人全平台使用同一昵称 |
| **B站 mid** | 签名（常含邮箱/微博/群号）、投稿、关注、粉丝 | `bili-space` / `bili-video`；搜「mid」看有没有被引用 | 主页是最稳定的自我描述 |
| **手机号** | 运营商、省份、注册年限 | 号段→运营商/省份（离线）；搜号码精确匹配；看招聘/二手/公示 | 号段表是公开常识 |
| **邮箱** | GitHub 身份、论文、注册站 | GitHub 搜邮箱；搜「邮箱」；看 Gravatar | 提交记录常留真实邮箱 |
| **QQ 号** | 昵称、年龄、地区、空间（需登录） | 搜 QQ 号；QQ 群搜索页看是否被收录 | QQ 号可当稳定 ID |
| **QQ 群号** | 群名、简介、群主、同好圈 | `qun.qq.com` 群资料；搜群号 | 群简介常写「XX 同学群/XX 项目」 |
| **微信号** | 昵称、地区、朋友圈（不可查） | 搜「微信号 + 昵称」看有无截图/文章 | 直接搜微信号命中率低 |
| **姓名** | 同名候选、单位、学校 | 必须配限定词（城市/单位/学校/年龄） | 中文同名率极高 |
| **姓名 + 单位** | 职务、报道、评审、专利 | 单位官网「新闻/公示/人才」栏目；搜「姓名 单位 公示」 | 官方页面可信度最高 |
| **姓名 + 学校** | 学院、年级、获奖、社团 | 教务处/学工办公示、获奖名单 PDF、学院公众号 | 公示名单常含姓名+学号 |
| **学号 / 工号** | 入学年份、院系、专业 | 反推编码规则；搜同格式学号 | 多数学校学号含年份+院系码 |
| **照片** | 地点、学校、工牌、活动 | 图片反查（人工）；看背景文字/门牌/校服；OCR 图中文字 | 图比文字更难伪造 |
| **头像** | 同一人的其他账号 | 图片反查；看是否有同一头像的其他站 | 头像复用在跨平台很常见 |
| **写作习惯 / 口头禅** | 跨平台的同一人 | 搜独特短语（加引号）；看标点/换行/emoji 习惯 | 文风是指纹 |
| **所在地 / 常去地点** | 学校、单位、住区（不精确化） | 搜「地名 + 昵称」；看同城标签 | 只用于印证，不用于定位 |
| **时间点（入学/入职）** | 年龄区间、届别 | 搜「年份 + 学校/单位 + 姓名」；对时间线做一致性检查 | 时间是最好用的排除器 |
| **游戏 ID** | 战绩站、公会、开黑群 | 战绩查询站、贴吧/群 | 游戏账号常绑社交 |
| **论文** | 导师、单位、合作者、邮箱 | 百度学术/知网；看通讯作者邮箱 | 学术页信息密度高 |
| **店铺 / 商品** | 店主身份、发货地、客服号 | 搜店名；看店铺资质页 | 电商页常留联系方式 |
| **域名 / 网站** | 备案主体、注册人 | ICP 备案查询（人工）；whois | 备案主体是实名信息 |
| **一段原话** | 出处、上下文、说话人 | 搜原句（加引号）；搜独特短语 | 引文可定位原文 |

## 二、三条真实可走的链

**链 A：昵称 → 邮箱 → 跨平台**
```
昵称「雾港信箱」
  → shiji.py bili-user 搜到 mid + 签名「粉丝群：725306418」
  → 群号进 QQ 群资料页（人工）→ 群主 = 另一个 QQ
  → 搜群号 → 贴吧/知乎提到这个群的帖子 → 发帖人 ID
```

**链 B：手机号 → 招聘帖 → 学校**
```
手机号 138xxxx1234
  → 搜号码 → 某招聘贴留了这个号（岗位：Java 实习）
  → 贴内写「XX 大学 2022 级」
  → 搜「XX 大学 2022 级 姓名」→ 学院公示名单 PDF
  → 名单含学号 → 学号规则反推院系
```

**链 C：姓名+单位 → 官方公示 → 职务**
```
「张伟 某某设计院」
  → 设计院官网「中标公示」出现「项目负责人 张伟」
  → 同一页面有项目编号与联系电话
  → 搜项目编号 → 政府采购网原始公告（更权威的版本）
```

## 三、扩展的节奏

1. **一轮只扩一层**。同时追五条线会把自己绕晕，也更容易把不同人的线索拼到一起。
2. **每条新线索先判「可信度 × 可验证性」**，优先追高分的那条（见 SKILL.md 第 1 步）。
3. **两轮没有新事实就停**。继续搜只会烧预算、也会开始编故事。
4. **扩出来的每一条都要落账**（`ledger add`），否则报告时想不起它从哪来。

## 四、看起来能扩、其实没用的

- **同名不同人**：只共享名字，不共享任何唯一标识 → 直接排除。
- **搬运/营销号**：同一段文字出现在十个号里，只有一个是最早的 → 追最早发布时间，其余当噪声。
- **公开的百科/新闻**：对公众人物有用，对普通人几乎为零（别把百科当「查到了」）。
- **「疑似」类内容**：论坛里「听说他是……」→ 只能进「线索」，不能进结论。
- **平台推荐位**：「你可能认识的人」不可作为证据，且容易越界。
