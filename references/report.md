# 报告模板

复制下面骨架，把 `[...]` 换成实际内容。**没有出处的段落直接删掉**，不要留「待补充」。

```markdown
# 公开信息核查报告 · [目标称谓]

- 调查时间：[2026-11-23]
- 线索来源：[用户提供 / 自查]
- 用途：[核实身份 / 自查数字足迹 / 尽调]
- 结论可信度：[高 / 中 / 低]（说明：已核实 N 项，高度可能 M 项，其余为线索）

## 一句话结论

[是/不是某单位某人；能确认到什么程度；最大的不确定性在哪]
```

## 写作规则

1. **一句话结论必须能独立成立**。读者只看这一句也知道该信到什么程度。
2. **每条结论都要能点开**。链接指向具体页面，不指向首页。
3. **区分「他是谁」和「这个号是不是他」**——这是两件事，别混在一栏里。
4. **打码**：手机号留前 3 后 2（`138****34`），邮箱留首字母（`x*******@hotmail.com`），住址只到区。
5. **不写概率**。写档位（已核实/高度可能/推测/线索/已排除）+ 依据。
6. **不写「疑似」「据传」当结论**。放到「未证实线索」，并给出验证方法。
7. **排除项不能省**。它证明你做过消歧，也保护被误伤的人。

## 篇幅

- 自查 / 简单核实：1 页，结论 + 证据表 + 局限。
- 尽调 / 维权：可以写长，但**每多一节都要多一条出处**，不要靠文字量充数。
