# 信源表：能拿到什么，怎么拿，值不值得

所有结论都标了**实测状态**（2026-11，家庭宽带 / 被代理接管的环境）。平台风控会变，动手前先 `doctor` 复测一次，别照抄结论。

## 一、分三档

| 档 | 含义 | 谁来做 |
| --- | --- | --- |
| **A 可脚本化** | 服务端直出内容，限速就能稳定拿 | `shiji.py` 直接跑 |
| **B 人工深链** | 对人不设防，对程序设防（登录墙/JS 渲染/风控） | `links` 生成清单，人打开读 |
| **C 不要碰** | 验证码、签名、账号池才能进 | 不做，见 `access.md` |

## 二、A 档（实测可拿到内容）

| 源 | 能拿到 | 实测 | 坑 |
| --- | --- | --- | --- |
| **Bing 中国** `cn.bing.com` | 标题/摘要/URL，10 条/页 | 稳定，最抗封 | **`site:` 不严格遵守**，结果会混别的站，要用 `--host` 做硬过滤；**两字生僻词会退化成单字字典页**（实测「炜梦」全返回「炜」的释义），这时换搜狗微信或加限定词 |
| **360 搜索** `so.com` | 标题/摘要/URL，7–12 条 | 可用，但约 10 次密集查询后弹验证码 | 弹一次冷却 15 分钟；`res-list` 里有富卡片要跳过；结果 URL 是跳转链，抓到要跟一次 |
| **搜狗微信** `weixin.sogou.com` | 文章标题、摘要、公众号名、日期 | 可用 | `/link` 的解析**必须和搜索同一个会话**；正文是 JS 空壳，抓不到（要浏览器）；频繁查会要验证码 |
| **B站公开接口** `api.bilibili.com` | 昵称→mid、签名、粉丝、投稿数、视频标题/UP/播放 | 稳定 | 不打首页拿 `buvid3` 会 412；`search/type` 有时要 wbi 签名，卡片接口不用 |
| **政府网搜索** `sousuo.www.gov.cn` | 政策/公示 JSON | 可用 | 只有政策库，不含地方 |
| **百度学术** `xueshu.baidu.com` | 论文标题/作者/年份 | 可用（HTML 内嵌 JSON） | 作者同名率高，必须配单位 |
| **天眼查移动版** `m.tianyancha.com` | 公司/法人/任职 | 返回内容，未细解析 | 只做交叉验证，别当唯一来源 |
| **DuckDuckGo html** | 英文/境外结果 | 可用 | 中文覆盖弱 |
| **GitHub API** | 用户、仓库、提交邮箱 | 稳定 | 提交邮箱常是真实邮箱，价值极高 |

## 四、昵称可检索性：为什么常常只查到一个平台

**中文互联网的注册键是手机号，昵称只是站内展示名。** 所以「昵称能查到什么」完全取决于平台有没有开放「昵称 → 公开主页」的入口。`probe` 命令会把这张表跑成实测结果。

| 类型 | 平台 | 昵称能否搜到 | 实测 |
| --- | --- | --- | --- |
| **内容型 · 开放** | B站 | ✅ 能（免登录接口） | 稳定 |
| | 网易云音乐 | ✅ 能（免登录接口） | 稳定 |
| | Gitee | ✅ 能（开放 API） | 稳定 |
| | GitHub | ✅ 能（开放 API，按用户名） | 稳定 |
| | CSDN / 掘金 | ✅ 内容搜索（昵称出现在文章里） | 可用 |
| **内容型 · 要登录** | 豆瓣 | ❌ 用户搜索需登录 | 登录墙 |
| | 知乎 | ❌ 搜索与主页都 403 | 风控 |
| | 微博 | ❌ 访客系统拦截 | 风控 |
| | 小红书 / 抖音 | ❌ JS 空壳 + 登录墙 | 不可判定 |
| | 贴吧 | ❌ 用户页 403 | 风控 |
| **工具型 · 无入口** | 淘宝 / 闲鱼 / 美团 / 游戏 / 政务 / 银行 | ❌ 无公开主页 | 查不到 |
| | 微信 / QQ | ❌ 昵称不对外索引 | 查不到 |

三条推论：

1. **「查不了」不等于「没注册」。** 这是昵称检索最大的误判来源。工具里 `probe` 专门把两种状态分开报。
2. **你注册过 ≠ 公开可查。** 只有你主动对外展示过的东西（B站签名、网易云歌单、GitHub 提交、论坛发帖）才会进公开网。
3. **换个钥匙才有增量。** 昵称查不全时，换手机号（招聘/二手/公示/快递）或邮箱（GitHub 提交、论文、论坛）；很多人跨站用英文 ID，用 `ids` 生成变体再 `probe`。

## 五、几个反直觉但重要的结论

1. **搜索引擎索引 = 免费的最大信源库。** 知乎、微博、小红书虽然关着门，但它们的标题和摘要大量存在于 Bing/360 的索引里。先扒索引，再决定要不要为正文付出成本。
2. **公众号是中文最深的内容池。** 大量「小红书爆款拆解」「某校某人的故事」「行业八卦」都以公众号形式存在，且可被搜狗微信检索到。哪怕只拿到标题+摘要+公众号名+日期，也足够定位一个人。
3. **B站主页是最容易被稳定读到的「自我描述」。** 签名栏里常见邮箱、微博、粉丝群号、学校；投稿标题能拼出时间线和兴趣。
4. **GitHub 提交邮箱是硬标识。** 一个 `xxx@qq.com` 能把你从 GitHub 带到 QQ 邮箱、微信、其他注册站。
5. **站内搜索 ≠ 搜索引擎。** 站内搜索要登录且只给最近的；搜索引擎给的是「历史全量但摘要」。两个都要试。

## 六、怎么自己复测

```bash
python scripts/shiji.py doctor            # 逐源探活，顺带看网络出口
python scripts/shiji.py probe "某个昵称"   # 昵称在 16 个平台的可达性矩阵
python scripts/shiji.py doctor --json     # 机器可读，便于写进报告附录
```

`doctor` 会：DNS 解析看是否被代理接管 → 各源各打一次真实查询 → 输出可用/冷却状态。**先 doctor 再搜**，能省掉一半「为什么搜不到」的困惑。
