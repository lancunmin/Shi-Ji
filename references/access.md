# 访问与边界：为什么不做「破解反爬」

这份文档记录实测结论，也说明这个工具**主动放弃**了什么。写清楚比藏着好——你会知道什么时候该停下来换路。

补充一个反直觉的事实：**连 B站 API、微信公众号文章页的 robots 也写着 `Disallow: /`**。所以「严格照 robots 办事」连现在能用的都要关掉——robots 是给索引爬虫的约定，不是法律，也不是「人的访问许可」。

本工具的立场：**做用户发起的、低量、带明确目的的单次检索**（类似浏览器），不做批量爬取、不做站内翻页收割、不并发轰炸。这两件事在技术上都叫「请求」，在性质上不是一回事。

## 二、为什么不做破解

社区里确实存在这些手段：打码平台、签名逆向（x-s / wbi）、账号池、代理 IP 池、无头浏览器指纹伪装。评估后不做，四个理由按重要性：

1. **法律**：《网络安全法》第 27 条禁止侵入网络、干扰正常功能、提供此类工具；《个人信息保护法》对个人信息处理有单独要求。查人拿到的绝大多数是个人信息，批量抓取的风险等级和「查一个人」完全不同。
2. **寿命**：签名算法和风控策略以周为单位迭代。写进开源项目的破解代码，三个月后就是一坨没人维护的负债。
3. **反噬**：账号池/异常流量会牵连你本机的登录态；代理池质量决定成败，而好池子要花钱。
4. **收益**：破了签名拿到的仍然是公开内容，而这些内容通过搜索索引、公众号转载、人工打开都能拿到。**破解只买到速度，买不到内容。**

## 三、网络出口：最容易被忽略的真凶

「中文站全都搜不到」时，先怀疑网络，再怀疑站点。

**症状**：知乎返回 `{"code":40362,"message":"您当前请求存在异常"}`；小红书返回「当前网络存在风险，请切换可靠网络」；微博跳登录；抖音出验证码；搜索引擎查几次就弹验证码。用**真浏览器**打开也一样。

**诊断**（`doctor` 自动做）：

```bash
nslookup www.zhihu.com      # 或 Resolve-DnsName
# 返回 198.18.x.x → 流量被代理/加速器的 TUN 接管（fake-ip）
```

`198.18.0.0/15` 是 sing-box / Clash 类工具的 fake-ip 段。一旦国内域名也解析到这里，你的请求就是从境外共享出口发出去的，平台按「异常网络」直接拦。

**处置顺序**：
1. 查国内站前断开代理/加速器（最有效）。
2. 或者把国内域名加进直连规则（分流），只让境外流量走代理。
3. 换出口：手机热点通常立刻可用。
4. 以上都不行 → 这确实是站点硬墙，转人工清单。

## 四、降级阶梯（卡住时按顺序走）

1. **换引擎**：Bing → 360 → 搜狗微信 → DDG。同一个词的结果重合度常常不到一半。
2. **换词形**：加限定词、换简繁、加年份、搜原句片段。
3. **换层级**：搜索引擎摘要 → 公众号元数据 → B站接口 → 页面正文。
4. **换人**：`links` 生成清单，让用户在浏览器里打开，把内容贴回来。
5. **记录未获取**：写进报告的「局限」，不要用推测填空。

## 五、人工交接协议

遇到登录墙，不要硬闯，也不要假装查到了。按这个流程交接：

```
1. 生成清单：shiji.py links "关键词" --out handoff.md
2. 交给用户：「这几个链接需要你登录后打开，把看到的正文贴回来（或截图）」
3. 用户贴回内容 → 用 ledger 记账，注明「用户提供 / 未经独立核实」
4. 报告里单独标注来源类型
```

这样拿到的东西**可信度标注清楚**，比自己爬到的更诚实，也更快。

## 六、硬边界（不做清单）

- 不碰社工库、撞库、身份证/手机号反查。
- 不绕登录墙、不破解验证码、不逆向签名、不用账号池。
- 不查未成年人；不输出身份证号、精确住址、银行卡、实时行踪。
- 不用于跟踪、骚扰、开盒、情感纠纷里的「查前任」。
- 报告里手机号/邮箱默认打码；结果落本地，不公开传播。
- 用途不合法就停手，并说明理由、给替代路径（平台举报 / 法律途径）。

### 为什么连「查我自己」也不用社工库

社工库的数据是**别人被泄露的个人信息**，买卖、持有、查询在《个人信息保护法》《刑法》第 253 条之一下面都有对应责任；而且公开叫卖的「社工库机器人」绝大多数是诈骗或钓鱼。哪怕只查自己，你也没有权限去调别人的数据。

### 想查「我到底泄露了多少」，走这些合法渠道

| 想知道 | 去哪儿 |
| --- | --- |
| 我的手机号绑了哪些互联网账号 | 工信部「一证通查 2.0」（支付宝/微信小程序，本人实名核验） |
| 我名下有几张电话卡 | 工信部「一证通查」电话卡版 |
| 我的邮箱出没出现在已知泄露事件 | Have I Been Pwned / Firefox Monitor（合法的公开服务，只查「是否出现」，不给原始数据） |
| 谁在用我的账号 | 各平台「登录设备管理」「第三方授权管理」逐个撤销 |
| 被人冒用/骚扰 | 12321 举报、平台申诉、必要时报警 |

这些渠道的共同点：**只向本人返回结果**，不给你别人的数据。这才是自查该有的边界。


## 七、给使用者的提醒

- 你查的是**人**，不是数据。报告可能被传播，写的时候就要想到当事人看到会怎样。
- 「查得到」不等于「该查」。动手前问一遍用途，比事后解释便宜。
- 这个工具的价值在于**诚实**：它会把「没查到」原样写出来，而不是编一个像样的答案。
